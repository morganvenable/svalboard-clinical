# DataHand Clinical Research Archive

This folder aggregates clinical studies, research findings, and ergonomic evidence
from the original DataHand Systems, Inc. website (datahand.com), recovered primarily
via the Wayback Machine, supplemented by academic databases and third-party sources.

## Contents

- `digest.md` - Comprehensive research digest (primary reference document)
- `archived-urls.md` - Index of all Wayback Machine archived URLs with access links
